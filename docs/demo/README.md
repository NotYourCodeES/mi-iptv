# Demo playlist

A small playlist of **fictional channels** to try Mi IPTV without an IPTV subscription.

Paste this URL in the app's setup page (**M3U link**):

```
https://raw.githubusercontent.com/NotYourCodeES/mi-iptv/main/docs/demo/playlist.m3u
```

The streams are public test streams commonly used to test video players:
[Big Buck Bunny](https://peach.blender.org/), [Sintel](https://durian.blender.org/) and
[Tears of Steel](https://mango.blender.org/) (Blender Foundation, CC BY), Apple's BipBop HLS sample,
and Akamai's live HLS test stream. Channel names and logos are made up for this demo.
